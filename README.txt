NEXUS MOBILE v0.2 — NEXUS McCAIN FACE EDITION

This ZIP contains a web-app/PWA prototype. The generated Nexus McCain portrait is now the main interface image instead of the animated orb.

Included:
- index.html: mobile interface with Nexus portrait, text input, tap-to-talk (where browser speech recognition is supported), and basic local responses
- assets/nexus-mccain.png: approved Nexus McCain portrait
- manifest.webmanifest and sw.js: installable/offline app-shell support when hosted over HTTPS
- icon.svg: app icon

Important limitations:
This is not an APK or a complete native Android application. It does not yet connect to a cloud AI model, provide persistent cross-device memory, run an always-listening wake word, or control Android calls/SMS/settings. Browser speech features and voices depend on the phone/browser.

To try it:
1. Extract the ZIP.
2. Host the folder on an HTTPS static web host.
3. Open the hosted address in Chrome on the Galaxy A06.
4. Use Chrome's menu > Add to Home screen / Install app.
5. Allow microphone access when prompted.

The MIT App Inventor project has not been modified or deleted.
